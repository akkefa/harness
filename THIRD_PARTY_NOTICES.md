# Third-party notices

deskagents is a Python implementation of the DeepSeek Harness architecture. Its
module layout, event vocabulary, session file format and behaviour follow the
pinned upstream TypeScript source recorded in [docs/upstream.json](docs/upstream.json),
and its tests adapt upstream test cases listed in
[docs/compatibility-cases.json](docs/compatibility-cases.json).

`tests/upstream_assets/` contains unmodified copies of upstream files
(`persistence-schema.json`, `v4.json`); [their manifest](tests/upstream_assets/MANIFEST.json)
records the source paths, commit and checksums.

The full MIT notices below cover that reference work. Preserve them with any
directly adapted code.
