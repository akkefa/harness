# Upstream audit — 2026-10-31

## Baseline

- DeepSeek Harness: `ce7073d51254c26cd63b22a60835b8f948deb447`
- Session format: v4
- deepseek-cordis: `>=0.1.1,<0.2`

The pin did not move during this audit. `scripts/upstream_changes.py --check` verifies
the package inventory and pinned persistence assets against the checkout.

## Distribution scope decision

`deskagents` now owns only the standalone core runtime represented by milestone
0.1 in `docs/upstream.json`. Entries from later milestones remain in the source
inventory so external plugin repositories can reuse the package mapping, but they are
not planned modules of this distribution. The boundary is documented in
`docs/plugin-roadmap.md`.

## Adopted for Phase 3 closure

- Upstream JSONL Zstandard framing: checksummed, concatenated frames with one header
  frame and one frame per durable event batch.
- Upstream default JSONL compression (`zstd`).
- Structural frame scanning, checksum validation, torn-final-frame recovery and
  durable rewrite before the next append.
- Plaintext and Zstandard fixtures generated by the pinned TypeScript implementation.
- Two-way verification: Python reads both committed `dsh` artifacts, and the pinned
  TypeScript `SessionPersistence` opens Python-written artifacts in both encodings.

## Intentional Python adaptations

- G1/G2 remain isolated in `deskagents._cordis` until deepseek-cordis exposes equivalent
  public APIs.
- G3 is not implemented by monkey-patching Cordis internals. Phase 5 agent teardown
  will use explicit Cordis-owned effects.
- v0–v3 session migrations remain outside the core reader; v4 is the only admitted
  logical format.

## Deferred to core Phases 4–6

- Full LLM seam, retry and token metering.
- Agent spine, tools, prompt assembly and minimal bundle.
- DeepSeek and OpenAI-compatible model adapters.

## External plugin inventory

Execution, Azure, context/control, web, MCP, skills, subagents, telemetry, settings,
credentials, storage, presets and PepGPT-specific providers are tracked for separate
plugin distributions and do not move the core upstream pin.
